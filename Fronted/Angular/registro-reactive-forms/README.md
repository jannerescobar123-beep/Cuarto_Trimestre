# Registro de Usuario con Reactive Forms

## Descripción

Este proyecto consiste en un formulario de registro desarrollado con Angular utilizando Reactive Forms.

El formulario valida la información ingresada por el usuario en tiempo real, mostrando mensajes de error personalizados y deshabilitando el botón de envío hasta que todos los datos sean válidos.

---

## Tecnologías utilizadas

- Angular 19
- TypeScript
- HTML5
- CSS3
- Reactive Forms

---

## Funcionalidades

- Registro de usuario.
- Validación de campos obligatorios.
- Validación de correo electrónico.
- Validación de usuario.
- Validación de contraseña.
- Confirmación de contraseña mediante validador personalizado.
- Validación de edad.
- Aceptación de términos y condiciones.
- Botón de envío habilitado únicamente cuando el formulario es válido.

---

## Instalación

Clonar el repositorio

```bash
git clone https://github.com/jannerescobar123-beep/Cuarto_Trimestre/tree/main/Fronted/Angular/registro-reactive-forms
```

Entrar al proyecto

```bash
cd registro-reactive-forms
```

Instalar dependencias

```bash
npm install
```

Ejecutar el proyecto

```bash
ng serve
```

Abrir en el navegador

```
http://localhost:4200
```
